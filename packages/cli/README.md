# fleetkit-cli

```bash
pip install fleetkit-cli
# or from a GitHub Release wheel:
# pip install https://github.com/blessed-bless/fleetkit/releases/download/v0.1.0/fleetkit_cli-0.1.0-py3-none-any.whl

fleetkit login --email admin@example.com --base-url http://localhost:8000
fleetkit overview
```

Config: `~/.fleetkit/config.json`. Full command list: [docs/cli.md](../../docs/cli.md).
