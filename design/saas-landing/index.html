Что внутри

Очередь, воркеры и алерты без зоопарка сервисов

Один FastAPI-бэкенд и React dashboard. Агенты ходят по API-ключу, UI — по JWT.

Jobs с retry

Claim через FOR UPDATE SKIP LOCKED, timeout, requeue и DLQ с ручным возвратом в очередь.

Workers + heartbeat

Регистрация, пульс и claim/complete/fail. Видно, кто жив, кто завис и на каком job.

Cron → job

Расписания превращаются в задачи. Webhooks с секретом кладут payload в ту же очередь.

Python SDK и CLI

Sync/async клиент и команды вроде fleetkit enqueue, overview и DLQ — без ручных curl.

Алерты

Правила вида queue.depth>20 уходят в Telegram или произвольный webhook.

Vault и guards

Секреты проекта шифруются. SSRF-guard, redaction и lockout на логин — в том же контуре.

Как ставят

Для тех, кто уже крутит ботов на VPS

# поднять API + UI + Postgres + Redis
cp .env.example .env
docker compose up --build

# UI:  http://localhost:8080
# API: http://localhost:8000/docs
# login: admin@example.com / fleetkit-admin
Запуск

Два файла — и очередь уже крутится

Compose поднимает API и dashboard. Дальше — API-ключ в воркер и первый job.

  • JWT для UI, API-ключи для агентов
  • Live WebSocket по проекту
  • Production-compose с образами из GHCR
